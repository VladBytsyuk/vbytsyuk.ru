# Владислав Быцюк — сайт-визитка

Адаптивный одностраничный сайт на русском языке. HTML, CSS и несколько строк JavaScript для года в подвале. Сборка, npm, база данных и сервер приложения не нужны. Все шрифты, фотография и PDF размещены локально; внешних запросов, аналитики и форм сбора данных нет.

## Локальный запуск

Из корня проекта:

```sh
python3 -m http.server 4173 --directory public
```

Откройте http://localhost:4173. Остановить сервер: Ctrl+C. Страницу можно также открыть напрямую из `public/index.html`.

## Структура

- `public/` — всё, что нужно разместить на сервере.
- `public/index.html` — тексты, проекты, контакты и метаданные.
- `public/styles.css` — адаптивная вёрстка и оформление.
- `public/assets/` — фото, резюме, шрифт Onest и его лицензия.
- `deploy/nginx.conf` — конфигурация Nginx для домена `vbytsyuk.ru`.

Контент перенесён из предоставленного резюме. В PDF есть две версии: даты работы взяты из первой, подробности проектов — из второй. Статус работы в Magnit Tech указан по резюме и не проверялся по внешним источникам. Графика проектов создана для сайта и не является скриншотами продуктов. Кнопка скачивания отдаёт оригинальный PDF, включая обе версии.

## Развёртывание на VPS с Nginx

Пример рассчитан на Ubuntu/Debian, домен `vbytsyuk.ru` и пользователя с доступом sudo. Реальное подключение к VPS в рамках создания сайта не выполнялось. Если ваш домен другой, замените его в конфигурации и командах. Поддомен `www` необязателен: удалите его из `server_name` и команды Certbot, если он не используется.

1. Направьте DNS A-записи домена и `www` на IPv4 VPS. Добавляйте AAAA только при настроенном IPv6. Разрешите входящие TCP 80 и 443 в используемом firewall, сохранив доступ по SSH.

2. На VPS установите Nginx и создайте каталог:

   ```sh
   sudo apt update
   sudo apt install nginx
   sudo mkdir -p /var/www/vbytsyuk.ru
   sudo chown "$(id -un):$(id -gn)" /var/www/vbytsyuk.ru
   ```

3. На локальном компьютере из корня проекта загрузите сайт (замените `USER` и `SERVER`):

   ```sh
   rsync -av public/ USER@SERVER:/var/www/vbytsyuk.ru/
   scp deploy/nginx.conf USER@SERVER:/tmp/vbytsyuk.ru.nginx.conf
   ```

   Копируйте именно содержимое `public/`, а не весь репозиторий. Команда не удаляет существующие файлы на VPS. Перед обновлением существующего сайта сохраните предыдущую версию каталога для отката.

4. На VPS подключите конфигурацию:

   ```sh
   sudo cp /tmp/vbytsyuk.ru.nginx.conf /etc/nginx/sites-available/vbytsyuk.ru
   sudo ln -s /etc/nginx/sites-available/vbytsyuk.ru /etc/nginx/sites-enabled/vbytsyuk.ru
   sudo nginx -t
   sudo systemctl reload nginx
   ```

   Символическую ссылку создайте только при первом развёртывании. Если домен уже обслуживается другой конфигурацией, обновите существующий блок вместо создания дубликата. Не отключайте другие сайты на сервере.

5. После обновления DNS включите HTTPS:

   ```sh
   sudo apt install certbot python3-certbot-nginx
   sudo certbot --nginx -d vbytsyuk.ru -d www.vbytsyuk.ru --redirect
   sudo certbot renew --dry-run
   ```

   Certbot дополнит HTTP-конфигурацию TLS и перенаправлением на HTTPS. При следующих обновлениях переносите только `public/`: не перезаписывайте дополненную Certbot конфигурацию исходным HTTP-шаблоном.

6. Проверьте https://vbytsyuk.ru: мобильную версию, переходы по разделам, скачивание PDF, email и телефон. Для последующих обновлений достаточно повторить `rsync` из шага 3; перезапуск Nginx не требуется.

## Изменение контента

Редактируйте `public/index.html`. Даты, должности и контакты — обычный HTML без скрытых источников данных. При замене PDF сохраните имя `assets/vladislav-bytsyuk-resume.pdf`, либо обновите все три ссылки. Изображение портрета — `assets/portrait.jpg`.

## Проверка

В браузере проверьте ширины 360, 390, 768 и 1440 px, отсутствие горизонтального скролла, управление ссылками с клавиатуры, скачивание резюме и работу страницы без JavaScript. Настройку Nginx перед применением проверяет `sudo nginx -t`; HTTPS и DNS проверяются уже на целевом VPS.
